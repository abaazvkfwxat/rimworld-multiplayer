## Overview

RimWorld Multiplayer enables full co-op play with deterministic simulation sync, letting multiple players manage the same colony simultaneously with individual cursor control and shared decision-making.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Multiplayer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Co-op Sync** | Deterministic game state kept in sync across all connected clients |
| **Individual Cursors** | Each player has their own camera and cursor without conflict |
| **Chat System** | In-game chat overlay for coordinating without alt-tabbing |
| **Pause Voting** | Any player can request a pause; majority vote applies it |
